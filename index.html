LOCAL STARTUP REQUIRED

Open DEAR-OWL through localhost

Browsers cannot run DESeq2, web workers, or local file parsing from a directly opened index.html. On Windows, double-click start-local.cmd. On macOS or Linux, run sh start-local.sh in Terminal. A local browser page will open automatically.

This does not upload the app or your count matrix to a remote server. Keep the launcher window open while analyzing.
