Home Help

Manual

DEAR-OWL performs two-group and one-factor multi-group differential gene expression analysis in the browser.

Use this page to prepare input data, select samples, set parameters, run the analysis, and interpret the output.

Requirements

  • Input data: Select a GExA dataset or upload a raw count matrix. The first column should contain gene IDs. The remaining columns should contain sample counts.
  • Sample groups: For two-group comparison, select control and treatment samples. For multi-group comparison, create three or more groups. At least two samples are required per group. Three or more biological replicates are recommended.
  • Comparable conditions: As a rule, compare samples within the same BioProject. The main difference between groups should be the treatment or condition of interest.
  • Browser resources: The analysis runs locally in the browser. Large datasets may require more time and memory.

DESeq2 uses raw integer counts for statistical testing. TPM values may be shown as expression context, but they are not used for differential expression testing.

Page Layout

Control Panel

The setup steps define the analysis. Select data, choose the design, assign samples, set parameters, select plots, and start the run.

Status Strip

The status strip shows progress, estimated memory use, and the webR runtime state.

Sample Tables

The control and treatment tables allow sample search, metadata filtering, and sample selection.

Results Area

After analysis, the Results section shows summary values, the result table, plots, download files, and the analysis log.

Step-by-step Workflow

  1. Open the Home page. In Step 1, select GExA dataset or Upload count matrix.
  2. In Step 2, select Two-group comparison or Multi-group comparison. Two-group comparison is the default.
  3. If using a GExA dataset, choose a dataset from the dropdown menu and check the dataset information.
  4. If uploading a count matrix, select a CSV, TSV, TXT, or gzip file. Count values must be non-negative integers.
  5. For two-group comparison, select control samples and treatment samples. In principle, select samples from one BioProject and keep tissue, stage, and cultivar consistent.
  6. For multi-group comparison, create groups, assign samples, select the reference group and comparison scope, and optionally run the DESeq2 global LRT.
  7. If sample information is unclear, check the BioProject, BioSample, or SRA record. If possible, trace the BioProject accession to the original publication before running the analysis.
  8. Set the analysis engine and thresholds. A useful starting point is DESeq2, FDR 0.05, and absolute log2 fold change 1.
  9. Select plots. MA and volcano plots are useful for pairwise contrasts. PCA and heatmap plots may be slower for large datasets.
  10. Check any warnings. Then click Run DEG analysis.
  11. In Results, review the summary, result table, plots, downloads, and analysis log. Interpret DEG in the context of the study design.

Sample Selection and BioProject Checks

  • General rule: Perform DEG analysis within the same BioProject whenever possible. This reduces differences caused by laboratory, sequencing, or data-processing effects.
  • Recommended comparison: Compare groups with the same BioProject, tissue, stage, cultivar, and other background conditions.
  • Avoid confounding: Do not mix multiple major differences between groups, such as treatment, tissue, cultivar, and project, in one comparison.
  • Metadata check: If sample labels are unclear, use the BioProject accession to inspect the BioProject, BioSample, and SRA records before analysis.
  • Original publication: When possible, read the source publication linked to the BioProject. Confirm treatment, genotype, tissue, developmental stage, replicate structure, and batch information.
  • Replicates: Two samples per group are allowed, but variance estimates are more reliable with three or more biological replicates.
  • Sample identity: Check SRA, BioSample, treatment, and attributes. Do not place the same sample in both groups.

A statistically significant result is not always biologically meaningful if the two groups come from different projects or poorly matched sample conditions.

Multi-group Comparison

Multi-group comparison is for one categorical factor with three or more groups. In DESeq2 mode, the global multi-group question is tested with LRT, while selected two-group contrasts are reported with Wald results. Batch terms, paired designs, interactions, and time-series models are not included in this mode.

Comparison Scopes

Reference vs all compares every non-reference group against the selected reference group. All pairwise creates every pairwise contrast once. Custom contrasts lets you choose numerator and denominator groups manually.

Numerator and Denominator

For B vs A, B is the numerator and A is the denominator. A positive log2 fold change indicates higher expression in B than in A. Up means significantly higher in the numerator group.

DESeq2 Global LRT

LRT is the DESeq2 test for the overall multi-group question. It tests whether expression differs in at least one group compared with the reduced model without group. It does not identify which specific groups differ, and it should not be interpreted with Up or Down direction or a log2 fold change threshold.

Pairwise Wald Contrasts

Wald results are used for the selected pairwise questions, such as B vs A or C vs B. These tables provide log2 fold change, Up/Down direction, and MA/volcano plots. Benjamini-Hochberg adjustment is performed separately within each pairwise comparison.

High-speed Pairwise Z-test

High-speed pairwise Z-test performs independent pairwise comparisons using library-size-normalized log2 CPM values. No global or omnibus test is performed in ultrafast mode.

Overlap Views

Use Venn-style overlap for 2 or 3 selected gene sets. When 4 or more sets are selected, use the UpSet-style intersection table. Up and Down are treated as separate gene sets.

Three or more biological replicates per group are recommended.

Set Analysis Parameters

Analysis Engine

R / DESeq2 (standard) is recommended for formal analysis. High-speed pairwise Z-test is intended for rapid screening.

Thresholds

A gene is counted as Up or Down only when both the significance threshold and the absolute log2 fold change threshold are met.

Filtering

Low-expression pre-filtering removes genes with very low counts before model fitting. The default setting is suitable for most first runs.

DESeq2 Options

The default size-factor estimation is ratio. For sparse GExA-style matrices, poscounts may help if DESeq2 reports normalization problems.

Recommended First Run

  • Use R / DESeq2 (standard) for the main analysis.
  • Use FDR threshold = 0.05 as a common starting point for multiple-testing correction.
  • Use absolute log2 fold change threshold = 1 to focus on genes with at least a two-fold difference.
  • Keep Low-expression pre-filtering enabled for most datasets.
  • Select MA and volcano plots first. Add PCA or heatmaps when sample-level structure must be checked.

Parameter Guide

FDR Threshold

FDR is the adjusted p-value after testing many genes. A lower value is stricter and gives fewer DEG.

Log2 Fold Change Threshold

This controls the minimum effect size. A value of 1 means a two-fold increase or decrease.

Minimum Total Count

Genes with total counts below this value across selected samples are removed before testing.

Independent Filtering

DESeq2 can remove genes with low statistical power during result generation. This is usually helpful.

Fit Type

This controls dispersion fitting in DESeq2. Use parametric first. Try local or mean only if DESeq2 reports a fit problem.

Size-factor Estimation

Use poscounts for sparse matrices with many zeros. This is often suitable for large public GExA-style datasets.

Cook's Cutoff

Cook's cutoff detects influential samples and is enabled by default. It may increase runtime; on slower or memory-limited systems, consider setting it to FALSE.

Test

This setting applies to two-group DESeq2 runs. In multi-group DESeq2 mode, the app automatically uses LRT for the global test and Wald results for the selected pairwise contrasts.

If you are uncertain, start with the default settings. Change parameters only when warnings, sample design, or a clear analysis plan requires it.

Results and Downloads

  • Summary cards: Review the number of tested genes, Up genes, Down genes, and selected thresholds.
  • Result table: Sort and filter genes by adjusted p-value, log2 fold change, base mean, TPM, or annotation. In multi-group mode, switch between global LRT and pairwise contrast tables.
  • Plots: Use the MA plot to inspect expression-dependent changes. Use the volcano plot to inspect effect size and significance. Use PCA and heatmaps to assess sample-level structure.
  • Downloads: Save result tables, normalized counts, selected samples, contrast summaries, direction matrices, parameters, and logs. Results are cleared when the page is reloaded.
  • Gene links: When available, external GExA and TGIF-DB links provide additional gene and expression information.

How to Read the Result Table

Direction

In two-group mode, Up means higher expression in treatment than in control. In multi-group pairwise tables, Up means higher expression in the numerator group than in the denominator group. Global LRT rows do not have Up or Down direction.

baseMean

This is the average normalized count across selected samples. Very low values should be interpreted with caution.

log2FoldChange

This is the estimated effect size for pairwise results. Positive values indicate higher expression in treatment for two-group mode, or in the numerator group for multi-group pairwise contrasts. Global LRT results should not be read as a single pairwise log2 fold change.

pvalue and padj

pvalue is the raw test result. padj is corrected for many tested genes and should usually be used for DEG selection.

TPM Columns

TPM values help describe expression level in each group. They are not used by DESeq2 for statistical testing.

Annotation

Annotation and homolog columns help assign possible gene function. They should be checked with external evidence when important.

Beginner Interpretation Guide

  • Do not select DEG by p-value alone. Use adjusted p-value, effect size, expression level, and study design together.
  • Check whether control and treatment samples separate as expected in PCA or heatmaps. Unexpected separation may indicate batch effects or mislabeled samples.
  • Genes with large fold change but very low expression may be unstable. Check baseMean and TPM before prioritizing them.
  • Report the selected thresholds, sample groups, BioProject, analysis engine, and main parameter settings with the results.

Troubleshooting

  • The Run button is disabled: Select at least two control samples and two treatment samples.
  • Loading takes a long time: Large datasets can be slow on first access. Reload the page if loading does not finish.
  • The uploaded file fails: Check that counts are integers and that there are no negative values, empty cells, duplicate sample names, or duplicate gene IDs.
  • DESeq2 fails: Try size-factor estimation with poscounts, set Cook's cutoff to FALSE, and disable heavy plots.
  • Too few DEG are detected: Check replicate number, sample matching, FDR threshold, log2 fold change threshold, and low-expression filtering.
  • Too many DEG are detected: Check for batch effects or mixed biological conditions between the two groups.
  • The browser is slow: Reduce the number of selected samples, disable PCA and heatmap plots, close other tabs, or reload the page.
