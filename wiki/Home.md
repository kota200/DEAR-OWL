# DEG on Web Wiki

DEG on Web is a browser-based application for two-group differential gene
expression analysis of plant RNA-seq count data.

## Analysis Principle

As a rule, compare samples within the same BioProject. This reduces unwanted
variation caused by differences in laboratory work, sequencing, and data
processing.

Before running an analysis, confirm the sample design from BioProject,
BioSample, and SRA records. If possible, also check the original publication.
